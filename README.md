# 📔 Personal Journal Manager

## 📌 Project Overview

**Personal Journal Manager** is a Python-based application designed to store and manage personal journal entries using **file handling**.

The user can add, view, search, and delete journal entries through a simple menu-driven system.

## ✨ Features

### ➕ Add New Entry

* Takes journal entry from the user.
* Automatically adds the current **date and time**.
* Saves the entry in `f.txt`.

### 👀 View All Entries

* Displays all saved journal entries.
* Shows a suitable message if no entries are available.

### 🔍 Search Entry

* Searches journal entries using a **keyword or date**.
* Displays matching entries.
* Shows a message when no match is found.

### 🗑️ Delete Entries

* Allows the user to delete all saved entries.
* Asks for confirmation before deleting.

### 🚪 Exit

* Exits the program safely with a goodbye message.

## 🛠️ Concepts Used

* **Class & Object** – Organizes journal operations.
* **File Handling** – Stores and manages journal data.
* **Append Mode (`a`)** – Adds new entries without removing old ones.
* **Read Mode (`r`)** – Reads and searches saved entries.
* **Write Mode (`w`)** – Clears the journal file.
* **Datetime** – Records date and time.
* **Exception Handling** – Handles file-related errors.
* **Loops & Conditions** – Creates the interactive menu.

## 📂 File Used

**`f.txt`** is used to permanently store the journal entries.

Each entry contains its **date, time, and journal text**.

## 🔄 Program Flow

**Start → Display Menu → Select Option → Perform Operation → Return to Menu → Exit**

## 🎯 Learning Outcome

This project provides practical knowledge of **Python File Handling, OOP, Exception Handling, and Menu-Driven Programming**. It demonstrates how data can be stored, retrieved, searched, and managed using a text file.
